# Secado

Calculador de problemas de ingeniería química enfocadas a secado para Windows usando Python y Flet.

## Stack

- **Interfáz:** Flet.
- **Tests:** pytest.
- **Cálculos psicrométiricos:** psychrolib. Se debe trabajar en sistema Inglés
- **Resolucion de ecuaciones:** math
- **Procedimiento:** Markdown de Flet.
- **Instalador de paquetes:** uv.

## Cálculos

Para secador tipo charola los cálculos estan en @./CALCULOS/charolas.md
Para secador continuo los cálculos se encuentran en @./CALCULOS/directo.md
Para secador rotatorio los cálculos se encuentran en @./CALCULOS/secador_rotatorio.md

## Manejo de errores
La app debe manejar excepción de errores para valores de psychrolib
